## Features
- Modern and professional UI/UX
- Fully responsive design
- Gradient buttons and sections for visual appeal
- Interactive hover effects on cards and buttons
- Testimonials with images and professional layout

## Setup Instructions
1. Clone the repo: `git clone https://github.com/Nikita-Pandit/ielts-homepage.git`
2. Navigate into project folder: `cd ielts-institute`
3. Install dependencies: `npm install`
4. Run the project: `npm run dev`
5. Open browser at: `http://localhost:5173/`

## Design Choices
- Used Tailwind CSS for rapid styling and responsive design.
- Gradient colors and hover effects for a modern look.
- Components are modular (Navbar, Hero, Features, Testimonials, Footer).
- Focused on mobile-first design and readability.
